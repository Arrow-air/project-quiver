# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be welcoming, assume good faith, and keep
discussions focused on the work. Harassment and personal attacks are not
tolerated anywhere the project operates — GitHub, Discord, the DAO forum,
or community calls.

Report conduct issues to the maintainers via the
[Arrow Discord](https://discord.gg/arrow) (direct message to a moderator
or drone engineering team member). Reports are handled confidentially.
